# Chess-Engine — Claude Code Instructions

This repository is a large, loosely-organized hobby project, and **most of it is inactive**.

**All active development lives in [`NN Engine/`](NN Engine/CLAUDE.md)** — a (mostly) standalone C++ chess engine driven through a Cython entry point and run under WSL. Despite the directory name, the current work is the C++ engine, not the older neural-network engine.

**Read [`NN Engine/CLAUDE.md`](NN Engine/CLAUDE.md) for the real instructions** — the file map, build/run workflow, and development rules. Unless told otherwise, assume work concerns the C++ engine described there, and flag (don't touch) anything outside that scope.
